# Vuemax Website

Static-first marketing site for Vuemax (fencing, steel & hardware, Zimbabwe).
Stack: PHP 8+ (shared includes), MySQL, Apache/cPanel.

## Structure

```
index.php, about.php, products.php, product-detail.php,
calculator.php, estimator.php, installations.php, faq.php,
contact.php, quote-results.php, 404.php   — pages (all use shared partials)
includes/config.php    — DB (PDO) + e()/usd() helpers
includes/header.php    — <head>, topbar, header, mobile drawer
includes/footer.php    — footer + shared <script> tag
assets/css/vuemax.css  — design system (single source of truth)
assets/js/main.js      — drawer, header state, scroll-reveal (.reveal)
api/*.php              — JSON endpoints (categories, subcategories, products,
                         product, estimate, quote-save, contact-send, projects)
sql/schema.sql         — full schema + seed data (incl. site_images, admin_users,
                         customers, orders, order_items, order_events)
admin/                 — back office (SB Admin UI template): login → dashboard;
                         images.php (image manager: upload/replace any site
                         image, stored in site_images, uploads to
                         assets/img/uploads/), products, quotes, messages,
                         customers, orders, order-view (status pipeline +
                         delivery tracking), users (admin accounts)
admin/inc.php          — admin session + CSRF + admin_head/admin_nav/
                         admin_footer (SB Admin chrome)
account/               — customer portal: login, register, index (orders),
                         order.php (tracking timeline), profile, logout
account/inc.php        — customer session (cust_id); pages set $base='../'
                         so shared header/footer links resolve
build.php              — renders .php pages to .html twins (local file:// browsing)
*.html (root)          — generated by build.php; links rewritten to .html
_archive/              — original static .html files (pre-conversion)
```

## Admin portal

- `/admin/login.php` — seeded account: `munyah` or `munyah777@gmail.com`
  (password: griezmann17). `is_protected=1` — can never be deleted/deactivated.
- `/admin/` dashboard: counts, recent quotes, quick actions, system info.
- `admin/images.php` — every `site_images` slot grouped by page; upload replaces it.
- `admin/customers.php` — create/edit/suspend customer accounts.
- `admin/orders.php` → `admin/order-view.php` — order pipeline
  (pending→confirmed→processing→packed→shipped→out_for_delivery→delivered),
  status buttons write `order_events` rows shown to customers; payment
  status (unpaid/deposit/paid), delivery address/tracking ref/driver/ETA,
  items + totals auto-recalc, internal notes (is_public=0).
- `admin/users.php` — manage admin accounts (create, reset pw, deactivate,
  delete); protected + self accounts can't be removed.
- Login accepts username OR email for both admin and customer portals.
- Pages call `site_image('key', 'fallback-url')` from `includes/config.php`;
  hero backgrounds use the `--hero-img` CSS var override.
- `logo` slot swaps the V emblem for an uploaded image (header/footer/drawer).

## Customer portal (`/account`)

- `account/login.php` + `register.php` — email+password auth, own session
  keys (`cust_id`), separate from admin.
- `account/index.php` — orders list; `account/order.php` — items, totals,
  pipeline progress bar + public tracking timeline (order_events is_public=1).
- `account/profile.php` — edit details + change password.
- Customers only ever see rows WHERE customer_id = their session id.
- Subdir pages set `$base='../'` before including header/footer.

## AI estimator

- `api/estimate.php` calls Groq (`GROQ_API_KEY`, `GROQ_MODEL` in
  `api/config.php`, currently `openai/gpt-oss-120b`) to extract fence type,
  perimeter, height and options; falls back to the rule engine on failure.
- Works without MySQL via a built-in fallback catalog.

## Conventions

- Shared classes live in `assets/css/vuemax.css` — do NOT redefine
  `.btn`, `.section`, `.page-hero`, `.product-card`, `.cta-band`, footer, etc.
  in page `$extraCss` except as scoped overrides.
- Mobile-first CSS: base styles = phones, `@media (min-width:…)` scales up.
- Add `class="reveal"` (+ `reveal-d1/d2/d3`) to elements for scroll-in animation.
- All internal links use relative `*.php` paths (`.htaccess` also maps clean
  URLs → `.php`). API calls use relative `api/*.php`.
- Quotes flow: calculator/estimator write `vuemax_quote` to sessionStorage →
  `quote-results.php` renders it. Phase 2: also POST to `api/quote-save.php`.
- After editing any .php page, run `php build.php` to regenerate the .html
  twins. On cPanel, `.htaccess` sets `DirectoryIndex index.php` so .php wins.

## Deploy (cPanel)

1. Upload everything except `_archive/` to `public_html/`.
2. Import `sql/schema.sql` via phpMyAdmin.
3. Set credentials in `api/config.php` (5 lines at top) and
   `includes/config.php`.
4. Set `DEBUG = false` in `api/config.php` when live.
